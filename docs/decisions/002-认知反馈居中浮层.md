# ADR-002: 认知反馈居中浮层

## 状态
Accepted / Implemented

## 背景

认知反馈（Cognitive Feedback）是 EchoMem 的五大核心功能之一，需要以可视化方式呈现会话中的知识结构。由于知识图谱需要较大的展示空间，右侧 320px 的面板不足以展示力导向图的交互体验。

## 决策

为认知反馈功能引入独立的居中浮动窗口，与常规右侧面板并存：
- 常规功能面板继续使用 `openCustomPanel()`（右侧 overlay）
- 认知反馈使用 `openCenterOverlay()`（居中、大尺寸浮层）

## 备选方案

| 方案 | 拒绝原因 |
|------|---------|
| 在右侧 320px 面板中渲染图谱 | 空间太小，力导向图交互体验差 |
| 全屏弹窗 | 会遮挡整个页面，用户无法参考对话内容 |
| 在当前页面内嵌入 | 需要操作目标网站的 DOM，侵入性太强 |

## 影响

1. 新增 `openCenterOverlay()` 函数，独立于 `openCustomPanel()`
2. 新增 `closeOverlayPanel()` 处理前序 overlay 恢复
3. `bindPanelEvents()` 增加 `closeMode` 参数
4. ECharts 作为 npm 依赖打包进扩展（CSP 限制）
5. 打包体积增加约 1.4MB

## 相关代码

- `src/core/panel-host.js` — `openCenterOverlay()`, `closeOverlayPanel()`
- `src/core/router.js` — 反馈面板路由
- `src/panels/feedback/index.js` — 图谱渲染
