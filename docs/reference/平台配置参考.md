# 平台配置参考

> 相关代码：`src/platforms/higo.js`, `src/platforms/deepseek.js`, `src/config/platforms.json`
> 检测流程：`docs/flows/platform-detection/检测流程.md`

## 概述

平台配置定义了 EchoMem 在目标网站上的检测规则、输入框选择器、标题栏入口和面板承载方式。每个平台是一个独立的配置对象，通过 `platformRegistry` 注册。

## 配置结构

```javascript
export const platformRegistry = {
  higo: higoPlatform,
  deepseek: deepseekPlatform
};
```

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `id` | string | 稳定平台 ID |
| `name` | string | 平台展示名称 |
| `detection` | object | 4 层检测配置 |
| `input` | object | 输入联想和内容插入使用的输入框配置 |
| `headerLauncher` | object | 可选的标题栏“图形 + EchoMem”入口配置 |
| `panelHost` | object | 面板承载方式 |
| `menuItems` | array | 功能导航列表 |

## detection 配置

```javascript
detection: {
  hostnames: ['localhost', '127.0.0.1', 'echo-agent.online', 'www.echo-agent.online', 'higo.world', '<ip>'],
  pathnamePrefixes: ['/home'],
  domFeatures: {
    optional: [
      { selector: '[data-testid="WorkspacesOutlinedIcon"]', description: '工作空间导航图标' },
      { selector: '[data-testid="MenuOpenIcon"]', description: '标题栏菜单图标' },
      { selector: 'textarea[id^="_r_"]', description: 'React 输入框' },
      { selector: '[data-testid="ArrowUpwardIcon"]', description: '发送按钮图标' }
    ]
  }
}
```

HIGO 使用“精确主机 + `/home` 路径 + 至少一个 EchoAgent 语义 DOM 标识”。页面标题、可见文案和通用 MUI 容器不再是硬门槛，避免首屏动态渲染、响应式布局或宿主组件调整导致误判。`/home/workspace` 首次直达由工作空间导航图标通过检测。

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `hostnames` | 允许的站点主机名；使用精确域名匹配，`'<ip>'` 表示允许任意 IPv4 地址 | `['localhost', 'echo-agent.online', 'www.echo-agent.online', '<ip>']` |
| `pathnamePrefixes` | 允许的路径前缀 | `['/home']` |
| `urlPatterns` | 兼容旧平台的 URL 子串匹配 | `['/home/session/', '/home/workspace/']` |

```javascript
input: {
  selector: 'textarea[id^="_r_"], [contenteditable="true"][role="textbox"]'
}
```

| 属性 | 类型 | 说明 |
|------|------|------|
| `selector` | string | 输入联想和资源内容插入使用的输入框 CSS 选择器 |

### HIGO 标题栏入口

HIGO 提供不依赖输入框的标题栏入口。扩展先通过左侧菜单图标或标题文本识别完整标题栏容器，再动态读取右侧第一个可见控件的位置，把入口以绝对定位方式紧贴在该控件左边；入口不参与标题栏的 flex 排版，因此不会挤偏居中的页面标题。工作空间页没有可见右侧控件时，入口直接占用空占位并贴到标题栏最右侧，不额外保留空档。只有无法识别标题栏容器时，才回退到分享按钮或右箭头锚点。点击后打开原有网页 overlay。聊天输入框附近不再注入 EchoMem 按钮。

```javascript
headerLauncher: {
  containerAnchorSelectors: [
    '[data-testid="MenuOpenIcon"]',
    '.MuiTypography-h6'
  ],
  anchorSelectors: [
    '[data-testid="ShareOutlinedIcon"]',
    '[data-testid="ShareIcon"]',
    '[data-testid="ChevronRightIcon"]'
  ],
  minHeaderWidth: 320,
  maxHeaderHeight: 96,
  controlGap: 4,
  preferredXRatio: 0.75,
  minXRatio: 0.18,
  maxXRatio: 0.94,
  maxTop: 120,
  logo: 'assets/echomem-lockup.png',
  title: '打开 EchoMem'
}
```

## panelHost 配置

所有平台统一使用 `overlay` 模式：

```javascript
panelHost: {
  type: 'overlay',
  overlayConfig: {
    position: 'right',    // 'right' | 'left' | 'center'
    width: '320px',       // 面板宽度
    backdrop: true        // 是否显示遮罩层
  }
}
```

## menuItems 配置

功能面板通过 `panelRegistry` 注册，`menuItems` 使用稳定 `panelId` 引用面板：

```javascript
menuItems: [
  { panelId: 'resources' },
  { panelId: 'association' },
  { panelId: 'feedback' },
  { panelId: 'skillStore' },
  { panelId: 'performance' }
]
```

面板标题和描述从 `src/panels/registry.js` 中读取。

## 扩展示例

### 场景：有侧边栏的页面

```javascript
export const anotherPlatform = {
  id: 'anotherPlatform',
  name: 'Another Platform',
  detection: {
    hostnames: ['chat.example.com'],
    pathnamePrefixes: ['/chat'],
    titleKeywords: ['Chat'],
    domFeatures: {
      required: [
        { selector: '.chat-container', description: '聊天容器' }
      ],
      optional: [
        { selector: 'textarea', description: '输入框' }
      ]
    },
    contentKeywords: ['chat']
  },
  input: {
    selector: 'textarea'
  },
  panelHost: {
    type: 'overlay',
    overlayConfig: {
      position: 'right',
      width: '320px',
      backdrop: true
    }
  },
  menuItems: [
    { panelId: 'resources' },
    { panelId: 'association' },
    { panelId: 'feedback' },
    { panelId: 'skillStore' },
    { panelId: 'performance' }
  ]
};
```

## 关键配置说明

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `detection` | 最多 4 层的可选检测配置 | 只执行已配置的层；优先使用 hostnames, pathnamePrefixes；urlPatterns 仅用于兼容旧平台 |
| `input.selector` | 输入框选择器，可用逗号分隔多个兼容目标 | `textarea[id^='_r_'], [contenteditable='true'][role='textbox']` |
| `headerLauncher` | HIGO 顶部标题栏组合标入口 | `{ containerAnchorSelectors, anchorSelectors, minHeaderWidth, maxHeaderHeight, controlGap, preferredXRatio, logo, title }` |
| `panelHost.type` | 面板类型 | `'overlay'`（统一使用浮层模式） |
| `panelHost.overlayConfig` | overlay 配置 | `{ position, width, backdrop }` |
| `menuItems` | EchoMem 功能导航列表 | `{ panelId }` |
