# 平台配置参考

> 相关代码：`src/platforms/higo.js`, `src/platforms/deepseek.js`, `src/config/platforms.json`
> 检测流程：`docs/flows/platform-detection/检测流程.md`

## 概述

平台配置定义了 EchoMem 在目标网站上的检测规则、入口注入方式和面板承载方式。每个平台是一个独立的配置对象，通过 `platformRegistry` 注册。

## 配置结构

```javascript
export const platformRegistry = {
  higo: higoPlatform,
  deepseek: deepseekPlatform
};
```

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `id` | string | 稳定平台 ID |
| `name` | string | 平台展示名称 |
| `detection` | object | 4 层检测配置 |
| `launcher` | object | EchoMem 入口按钮挂载配置 |
| `panelHost` | object | 面板承载方式 |
| `menuItems` | array | 功能导航列表 |

## detection 配置

```javascript
detection: {
  urlPatterns: ['/home/session/', '/home/workspace/'],
  titleKeywords: ['Higo', 'HIGO', 'Higo2', 'Higo Office'],
  domFeatures: {
    required: [
      { selector: '.MuiDrawer-root', description: 'MUI 抽屉组件' },
      { selector: '.MuiPaper-root', description: 'MUI Paper 容器' }
    ],
    optional: [
      { selector: 'textarea[id^="_r_"]', description: 'React 输入框' },
      { selector: '[data-testid="ArrowUpwardIcon"]', description: '发送按钮图标' },
      { selector: '.MuiDrawer-anchorRight', description: '右侧抽屉' }
    ]
  },
  contentKeywords: ['higo', 'HIGO', 'Higo2']
}
```

## launcher 配置

```javascript
launcher: {
  text: 'EchoMem',
  containerSelector: '.MuiPaper-root',
  validateSelectors: {
    textarea: 'textarea[id^="_r_"]',
    sendButton: '[data-testid="ArrowUpwardIcon"]'
  },
  style: {
    display: 'flex',
    padding: '0 12px 8px'
  },
  insertPosition: 'before'
}
```

| 属性 | 类型 | 说明 |
|------|------|------|
| `text` | string | 入口按钮文字 |
| `containerSelector` | string | 入口插入的容器 CSS 选择器 |
| `validateSelectors` | object | 验证容器是否有效的选择器 |
| `style` | object | launcher bar 的样式 |
| `insertPosition` | string | 插入位置：`'after'`、`'before'`、`'append'` |

## panelHost 配置

所有平台统一使用 `overlay` 模式：

```javascript
panelHost: {
  type: 'overlay',
  overlayConfig: {
    position: 'right',    // 'right' | 'left' | 'center'
    width: '320px',       // 面板宽度
    backdrop: true        // 是否显示遮罩层
  }
}
```

## menuItems 配置

功能面板通过 `panelRegistry` 注册，`menuItems` 使用稳定 `panelId` 引用面板：

```javascript
menuItems: [
  { panelId: 'resources' },
  { panelId: 'association' },
  { panelId: 'feedback' },
  { panelId: 'skillStore' },
  { panelId: 'performance' }
]
```

面板标题和描述从 `src/panels/registry.js` 中读取。

## 扩展示例

### 场景：有侧边栏的页面

```javascript
export const anotherPlatform = {
  id: 'anotherPlatform',
  name: 'Another Platform',
  detection: {
    urlPatterns: ['/chat/'],
    titleKeywords: ['Chat'],
    domFeatures: {
      required: [
        { selector: '.chat-container', description: '聊天容器' }
      ],
      optional: [
        { selector: 'textarea', description: '输入框' }
      ]
    },
    contentKeywords: ['chat']
  },
  launcher: {
    text: 'EchoMem',
    containerSelector: '.input-wrapper',
    validateSelectors: {
      textarea: 'textarea',
      sendButton: '.send-btn'
    },
    style: {
      display: 'flex',
      gap: '8px',
      padding: '0 12px 8px'
    },
    insertPosition: 'before'
  },
  panelHost: {
    type: 'overlay',
    overlayConfig: {
      position: 'right',
      width: '320px',
      backdrop: true
    }
  },
  menuItems: [
    { panelId: 'resources' },
    { panelId: 'association' },
    { panelId: 'feedback' },
    { panelId: 'skillStore' },
    { panelId: 'performance' }
  ]
};
```

## 关键配置说明

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `detection` | 4层检测配置 | urlPatterns, titleKeywords, domFeatures, contentKeywords |
| `launcher.text` | 入口按钮文字 | `EchoMem` |
| `launcher.containerSelector` | 入口插入的容器 | `.MuiPaper-root`, `.toolbar` |
| `launcher.validateSelectors` | 验证容器的选择器 | `{ textarea: 'textarea', sendButton: '.send-btn' }` |
| `launcher.insertAfter` | 插入到指定元素之后（优先级高于 insertPosition） | `'._020ab5b'` |
| `launcher.getBackgroundColor` | 动态获取入口栏背景色函数 | `() => '#fff'` |
| `launcher.insertPosition` | 插入位置 | `'after'`, `'before'`, `'append'` |
| `panelHost.type` | 面板类型 | `'overlay'`（统一使用浮层模式） |
| `panelHost.overlayConfig` | overlay 配置 | `{ position, width, backdrop }` |
| `menuItems` | EchoMem 功能导航列表 | `{ panelId }` |
