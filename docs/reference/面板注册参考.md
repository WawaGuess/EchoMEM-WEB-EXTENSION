# 面板注册参考

> 相关代码：`src/panels/registry.js`, `src/panels/index.js`
> 平台配置：`docs/reference/平台配置参考.md`

## 概述

功能面板通过 `panelRegistry` 注册，平台菜单通过稳定 `panelId` 引用面板。面板模块负责渲染对应功能的 HTML 内容。

## 注册结构

```javascript
// src/panels/registry.js
export const panelRegistry = {
  resources: { id: 'resources', title: '资源管理', ... },
  association: { id: 'association', title: '输入联想', ... },
  feedback: { id: 'feedback', title: '认知反馈', ... },
  skillStore: { id: 'skillStore', title: 'Skill 管理', ... },
  performance: { id: 'performance', title: '效能', ... }
};
```

## 平台菜单配置

```javascript
menuItems: [
  { panelId: 'resources' },
  { panelId: 'association' },
  { panelId: 'feedback' },
  { panelId: 'skillStore' },
  { panelId: 'performance' }
]
```

面板标题和描述从 `panelRegistry` 中读取，颜色通过 `panelId` 映射到固定的 `panelStyles` 配置。

## 配色映射

| panelId | 图标容器渐变 | 强调色 accent |
|---------|-------------|--------------|
| `resources` | `#8ab0c8 → #6a90a8` | `#5a7e95` |
| `association` | `#8ac89a → #6aa87a` | `#5a906a` |
| `feedback` | `#b0a0c8 → #9080a8` | `#807098` |
| `skillStore` | `#d8b87a → #b8985a` | `#a8884a` |
| `performance` | `#d89888 → #b87868` | `#a86858` |

## 面板目录结构

```
src/panels/
├── registry.js          # 面板注册表
├── index.js             # 统一导出
├── echomem/             # EchoMem 功能导航首页
├── resource/            # 资源管理面板
├── association/         # 输入联想面板
├── feedback/            # 认知反馈面板
├── skill-store/         # Skill 管理面板
└── performance/         # 效能面板
```

## 新增面板步骤

1. 在 `src/panels/` 下创建新目录
2. 实现 `getXxxContent()` 返回 HTML 字符串
3. 在 `src/panels/registry.js` 中注册
4. 在 `src/panels/index.js` 中导出
5. 在平台配置的 `menuItems` 中添加 `{ panelId: 'xxx' }`
6. 在 `panelStyles` 中添加配色映射
