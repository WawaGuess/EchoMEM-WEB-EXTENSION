# 外部接口清单

本文档汇总 EchoMem Web Extension 运行期间调用的所有外部网络接口，包括请求方法、URL、请求头、请求体与响应体字段说明，以及每个接口的用途。

> **说明**：以下响应体字段根据源码中对返回值的消费方式反推整理。若后端 OpenAPI/接口规范发生变更，需以实际后端文档为准。

---

## 1. 公共请求头

所有发往 EchoMem 记忆后端引擎（默认 `http://127.0.0.1:8010`）的请求，都会附加以下公共头（由 `EchoMemClient._buildHeaders()` 构建）：

| 头字段 | 是否必填 | 来源 | 说明 |
|--------|----------|------|------|
| `X-Auth-Key` | 是 | `config.authKey` | API 密钥认证；后端通过该 key 推导租户/用户身份 |

对于带有 JSON body 的 POST/DELETE 请求，还会附加：

| 头字段 | 值 | 说明 |
|--------|-----|------|
| `Content-Type` | `application/json` | 请求体为 JSON |

> 请求体中**禁止**携带 `user_id` 或 `tenant_id`，后端会显式拒绝。

## 2. EchoMem 记忆后端引擎接口

默认基础地址：`http://127.0.0.1:8010`

### 2.1 健康检查

| 项目 | 内容 |
|------|------|
| **用途** | 在「记忆后端引擎连接配置」面板中测试后端是否可达 |
| **调用方** | `src/panels/echomem/config.js` |
| **方法 / URL** | `GET /health` |

**请求头**：`X-Auth-Key`。

**请求体**：无。

**响应体**：

```json
{
  "status": "ok",
  "service": "echomem",
  "version": "..."
}
```

### 2.2 记忆召回（输入联想）

| 项目 | 内容 |
|------|------|
| **用途** | 用户在聊天输入框输入时，根据当前文本召回历史记忆，用于生成输入联想建议 |
| **调用方** | `src/core/input-tracker.js` |
| **方法 / URL** | `POST /api/retrieval/search` |

**请求头**：`X-Auth-Key` + `Content-Type: application/json`。

**请求体**：

```json
{
  "query": "用户当前输入的文本",
  "agent_id": "echoagent",
  "session_id": "可选当前会话 ID",
  "limit": 5,
  "include_explain": false
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | 是 | 用户输入文本 |
| `agent_id` | string | 是 | 应用级隔离标识，默认 `echoagent` |
| `session_id` | string | 否 | 当前会话 ID，用于会话锚定召回 |
| `limit` | number | 否 | 返回结果数量上限，默认 5 |
| `include_explain` | boolean | 否 | 是否返回召回解释 |

**响应体**：

```json
{
  "status": "ok",
  "result": {
    "items": [
      {
        "text": "记忆文本",
        "score": 0.85,
        "kind": "...",
        "source": "...",
        "evidence_uri": "..."
      }
    ],
    "explain": "..."
  }
}
```

源码消费：`result.items` 数组，元素至少读取 `text`、`score` 字段。

### 2.3 打开会话

| 项目 | 内容 |
|------|------|
| **用途** | 会话录制开始时，在 EchoMem 后端打开/创建一个会话 |
| **调用方** | `src/core/session-recorder.js` |
| **方法 / URL** | `POST /api/sessions/open` |

**请求头**：`X-Auth-Key` + `Content-Type: application/json`。

**请求体**：

```json
{
  "agent_id": "echoagent",
  "session_id": "页面聊天会话 ID（可选）",
  "run_id": "...（可选）",
  "metadata": {}
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `agent_id` | string | 是 | 应用级隔离标识 |
| `session_id` | string | 否 | 页面侧会话标识 |
| `run_id` | string | 否 | 运行 ID |
| `metadata` | object | 否 | 附加元数据 |

**响应体**：

```json
{
  "status": "ok",
  "result": {
    "scope": {
      "session_id": "sess_xxx"
    }
  }
}
```

源码消费：`result.scope.session_id`。

### 2.4 追加消息

| 项目 | 内容 |
|------|------|
| **用途** | 将页面聊天中新出现的用户/助手消息追加到 EchoMem 对应会话 |

| **方法 / URL** | `POST /api/sessions/{session_id}/messages` |

**请求体**：

```json
{
  "role": "user",
  "content": "消息文本内容"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `role` | string | 是 | 消息角色，如 `user` / `assistant` |
| `content` | string | 是 | 消息正文 |

**响应体**：

```json
{
  "status": "ok",
  "result": {
    "message": { "id": "msg_xxx" }
  }
}
```

### 2.6 添加资源

| 项目 | 内容 |
|------|------|
| **用途** | 资源管理上传文件：前端读取文件内容后调用，注册为 EchoMem 资源 |
| **调用方** | `src/panels/resource/import.js` |
| **方法 / URL** | `POST /api/resources` |

**请求头**：`X-Auth-Key` + `Content-Type: application/json`。

**请求体**：

```json
{
  "content": "文件内容（文本或 base64）",
  "name": "report.pdf",
  "content_type": "application/pdf",
  "tags": [],
  "metadata": { "source": "EchoMem extension", "encoding": "base64" }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `content` | string | 是 | 文件内容；文本文件直接传文本，二进制文件传 base64 |
| `name` | string | 是 | 原始文件名 |
| `content_type` | string | 否 | MIME 类型 |
| `tags` | string[] | 否 | 标签 |
| `metadata` | object | 否 | 附加元数据；二进制文件可带 `encoding: "base64"` |

**响应体**：

```json
{
  "status": "ok",
  "result": {
    "resource_id": "res_xxx",
    "uri": "echo://resources/..."
  }
}
```

源码消费：`resource_id` 用于后续删除。

### 2.10 文件系统列表

| 项目 | 内容 |
|------|------|
| **用途** | 资源管理、Skill 商店中浏览目录内容，列出指定 URI 下的资源/文件 |
| **调用方** | `src/panels/resource/manage.js`、`src/panels/resource/import.js`、`src/panels/skill-store/index.js` |
| **方法 / URL** | `GET /fs/ls?uri=...&output=agent&abs_limit=128&...` |

**请求头**：`X-Auth-Key`。

**Query 参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `uri` | string | 是 | 要列出的目录 URI，如 `echo://resources`、`echo://skills`（**无尾部斜杠**，后端 `EchoUri.parse` 会拒绝末尾 `/`） |
| `simple` | boolean | 否 | 简化输出 |
| `recursive` | boolean | 否 | 递归列出 |
| `output` | string | 否 | 输出格式，源码中常用 `"agent"` |
| `abs_limit` | number | 否 | 绝对数量限制，常用 128 |
| `show_all_hidden` | boolean | 否 | 是否显示隐藏项 |
| `node_limit` | number | 否 | 节点数量限制 |

**响应体**：

```json
{
  "status": "ok",
  "result": [
    {
      "uri": "echo://resources/res_xxx",
      "name": "report.pdf",
      "resource_id": "res_xxx",
      "kind": "file",
      "size": 1024,
      "updated_at": "2026-06-22T10:00:00Z",
      "abstract": "..."
    }
  ]
}
```

源码消费：数组或 `result.entries` 数组；条目类型通过 `kind: 'directory'/'file'` 判断，不再使用 `isDir`。修改时间字段为 `updated_at`。

### 2.11 读取内容

| 项目 | 内容 |
|------|------|
| **用途** | 资源管理中查看资源内容、Skill 商店中读取 SKILL.md 正文 |
| **调用方** | `src/panels/resource/manage.js`、`src/panels/skill-store/index.js` |
| **方法 / URL** | `GET /fs/read?uri=...&offset=0&limit=...` |

**请求头**：`X-Auth-Key`。

**Query 参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `uri` | string | 是 | 内容 URI |
| `offset` | number | 否 | 偏移量 |
| `limit` | number | 否 | 读取长度限制 |

**响应体**：

```json
{
  "status": "ok",
  "result": {
    "uri": "echo://resources/res_xxx/content",
    "text": "文件内容..."
  }
}
```

源码消费：`EchoMemClient.fsRead()` 优先返回 `result.text`，兼容 `result.content` 和字符串响应。

## 3. 用户会话统计接口

| 项目 | 内容 |
|------|------|
| **基础地址** | `http://127.0.0.1:8000` |
| **用途** | 效能概览面板展示用户在本地的会话级 Token 统计（总 Token、会话数、轮次数、Input/Output Token） |
| **调用方** | `background.js`（由 `src/panels/performance/index.js` 通过 `chrome.runtime.sendMessage` 代理调用） |
| **方法 / URL** | `GET /api/stats/summary` |

**请求头**：无特殊头。

**请求体**：无。

**响应体**：

```json
{
  "total_sessions": 10,
  "total_turns": 42,
  "total_input_tokens": 1234,
  "total_output_tokens": 5678,
  "total_tokens": 6912,
  "since": "2026-01-01T00:00:00.000Z"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `total_sessions` | number | 总会话数 |
| `total_turns` | number | 总对话轮次数 |
| `total_input_tokens` | number | 累计 Input Tokens |
| `total_output_tokens` | number | 累计 Output Tokens |
| `total_tokens` | number | 累计总 Tokens |
| `since` | string (ISO 8601) | 统计起始时间 |

源码消费：`src/panels/performance/index.js` 的 `fetchPerformanceData()` 将上述字段映射为 `totalSessions`、`totalTurns`、`totalInputTokens`、`totalOutputTokens`、`totalTokens`、`since`。

## 4. 接口汇总表

| 用途 | 调用方 | 方法 | URL | 请求体类型 |
|------|--------|------|-----|------------|
| 后端健康检查 | 配置面板 | `GET` | `/health` | 无 |
| 记忆召回/输入联想 | `input-tracker.js` | `POST` | `/api/retrieval/search` | JSON |
| 打开会话 | `session-recorder.js` | `POST` | `/api/sessions/open` | JSON |
| 追加会话消息 | `session-recorder.js` | `POST` | `/api/sessions/{id}/messages` | JSON |
| 提交会话 | `session-recorder.js` | `POST` | `/api/sessions/{id}/commit` | JSON |
| 添加资源 | 资源面板 | `POST` | `/api/resources` | JSON |
| 删除资源 | 资源面板 | `DELETE` | `/api/resources/{resource_id}` | 无 |
| 添加 Skill | Skill 商店 | `POST` | `/api/skills` | JSON |
| 删除 Skill | Skill 商店 | `DELETE` | `/api/skills/{name}` | 无 |
| 列出目录 | 资源/Skill 面板 | `GET` | `/fs/ls` | Query |
| 读取内容 | 资源/Skill 面板 | `GET` | `/fs/read` | Query |
| 后端使用量 | 效能面板 | `GET` | `/api/v1/usage`（stub） | 无 |
| 用户会话 Token 统计 | 效能面板（经 Background） | `GET` | `http://127.0.0.1:8000/api/stats/summary` | 无 |
