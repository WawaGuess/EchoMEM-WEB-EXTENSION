# 外部接口清单

本文档汇总 EchoMem Web Extension 运行期间调用的所有外部网络接口，包括请求方法、URL、请求头、请求体与响应体字段说明，以及每个接口的用途。

> **说明**：以下响应体字段根据源码中对返回值的消费方式反推整理。若后端 OpenAPI/接口规范发生变更，需以实际后端文档为准。

---

## 1. 公共请求头

所有发往 OpenViking 记忆后端引擎（默认 `http://127.0.0.1:1933`）的请求，都会附加以下公共头（由 `OpenVikingClient._buildAuthHeaders()` 构建）：

| 头字段 | 是否必填 | 来源 | 说明 |
|--------|----------|------|------|
| `X-OpenViking-Agent` | 是 | `config.agentId` | 固定为 `echomem-extension`，标识调用方代理 |
| `X-API-Key` | 当 `authEnabled=true` 时 | `config.apiKey` | API 密钥认证 |
| `X-OpenViking-Account` | 当 `authEnabled=true` 时 | `config.accountId` | 账户标识，默认 `default` |
| `X-OpenViking-User` | 当 `authEnabled=true` 时 | `config.userId` | 用户标识，默认 `default` |

对于带有 JSON body 的 POST/DELETE 请求，还会附加：

| 头字段 | 值 | 说明 |
|--------|-----|------|
| `Content-Type` | `application/json` | 请求体为 JSON |

> 文件临时上传接口（`/api/v1/resources/temp_upload`）**不**手动设置 `Content-Type`，由浏览器自动填充 `multipart/form-data; boundary=...`。

## 2. OpenViking 记忆后端引擎接口

默认基础地址：`http://127.0.0.1:1933`

### 2.1 健康检查

| 项目 | 内容 |
|------|------|
| **用途** | 在 OpenViking 连接配置面板中测试后端是否可达 |
| **调用方** | `src/panels/echomem/config.js` |
| **方法 / URL** | `GET /health` |

**请求头**：仅公共认证头（`X-OpenViking-Agent` 等），无 `Content-Type`。

**请求体**：无。

**响应体**：

```json
{
  "status": "ok"
}
```

> 源码中只判断 `response.ok`，不解析具体字段。

### 2.2 记忆召回（输入联想）

| 项目 | 内容 |
|------|------|
| **用途** | 用户在聊天输入框输入时，根据当前文本召回历史记忆，用于生成输入联想建议 |
| **调用方** | `src/core/input-tracker.js` |
| **方法 / URL** | `POST /api/v1/search/find` |

**请求头**：公共认证头 + `Content-Type: application/json`。

**请求体**：

```json
{
  "query": "用户当前输入的文本",
  "target_uri": "viking://user/memories",
  "limit": 5,
  "score_threshold": 0
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | 是 | 用户输入文本 |
| `target_uri` | string | 否 | 搜索目标 URI，默认 `viking://user/memories` |
| `limit` | number | 否 | 返回结果数量上限，默认 5 |
| `score_threshold` | number | 否 | 相似度阈值，默认 0 |

**响应体**：

```json
{
  "status": "ok",
  "result": {
    "memories": [
      {
        "overview": "记忆概述",
        ...
      }
    ]
  }
}
```

源码消费：`result.memories` 数组，每个元素至少读取 `overview` 字段用于生成补全建议。

### 2.3 创建会话

| 项目 | 内容 |
|------|------|
| **用途** | 会话录制开始时，在 OpenViking 后端创建一条会话记录，建立页面聊天会话与后端会话的映射 |
| **调用方** | `src/core/session-recorder.js` |
| **方法 / URL** | `POST /api/v1/sessions` |

**请求头**：公共认证头 + `Content-Type: application/json`。

**请求体**：

```json
{
  "session_id": "页面聊天会话 ID（可选）"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `session_id` | string | 否 | 页面侧会话标识，存在时传给后端 |

**响应体**：

```json
{
  "status": "ok",
  "result": {
    "session_id": "ov_xxx",
    "id": "ov_xxx"
  }
}
```

源码消费：`result.session_id || result.id || result`，保存为 `openVikingSessionId` 并写入 `chrome.storage.local`。

### 2.9 文件系统列表

| 项目 | 内容 |
|------|------|
| **用途** | 资源管理、Skill 商店中浏览目录内容，列出指定 URI 下的资源/文件 |
| **调用方** | `src/panels/resource/manage.js`、`src/panels/resource/import.js`、`src/panels/skill-store/index.js` |
| **方法 / URL** | `GET /api/v1/fs/ls?uri=...&output=agent&abs_limit=128&...` |

**请求头**：公共认证头，无 `Content-Type`。

**Query 参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `uri` | string | 是 | 要列出的目录 URI |
| `simple` | boolean | 否 | 简化输出 |
| `recursive` | boolean | 否 | 递归列出 |
| `output` | string | 否 | 输出格式，源码中常用 `"agent"` |
| `abs_limit` | number | 否 | 绝对数量限制，常用 128 |
| `show_all_hidden` | boolean | 否 | 是否显示隐藏项 |
| `node_limit` | number | 否 | 节点数量限制 |

**响应体**：

```json
{
  "status": "ok",
  "result": {
    "entries": [
      {
        "uri": "viking://...",
        "name": "文件名",
        ...
      }
    ]
  }
}
```

源码消费：`result.entries` 数组，遍历后调用 `fsStat`、`contentOverview`、`fsRm`、`contentRead` 等。

## 3. 用户会话统计接口

| 项目 | 内容 |
|------|------|
| **基础地址** | `http://127.0.0.1:8000` |
| **用途** | 效能概览面板展示用户在本地的会话级 Token 统计（总 Token、会话数、轮次数、Input/Output Token） |
| **调用方** | `background.js`（由 `src/panels/performance/index.js` 通过 `chrome.runtime.sendMessage` 代理调用） |
| **方法 / URL** | `GET /api/stats/summary` |

**请求头**：无特殊头。

**请求体**：无。

**响应体**：

```json
{
  "total_sessions": 10,
  "total_turns": 42,
  "total_input_tokens": 1234,
  "total_output_tokens": 5678,
  "total_tokens": 6912,
  "since": "2026-01-01T00:00:00.000Z"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `total_sessions` | number | 总会话数 |
| `total_turns` | number | 总对话轮次数 |
| `total_input_tokens` | number | 累计 Input Tokens |
| `total_output_tokens` | number | 累计 Output Tokens |
| `total_tokens` | number | 累计总 Tokens |
| `since` | string (ISO 8601) | 统计起始时间 |

源码消费：`src/panels/performance/index.js` 的 `fetchPerformanceData()` 将上述字段映射为 `totalSessions`、`totalTurns`、`totalInputTokens`、`totalOutputTokens`、`totalTokens`、`since`。
