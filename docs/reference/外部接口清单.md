# 外部接口清单

本文档汇总 EchoMem Web Extension 运行期间调用的所有外部网络接口，包括请求方法、URL、请求头、请求体与响应体字段说明，以及每个接口的用途。

> **说明**：以下响应体字段根据源码中对返回值的消费方式反推整理。若后端 OpenAPI/接口规范发生变更，需以实际后端文档为准。

---

## 1. 公共请求头

所有发往 EchoMem 记忆后端引擎（默认 `http://127.0.0.1:8010`）的请求，都会附加以下公共头（由 `EchoMemClient._buildHeaders()` 构建）：

| 头字段 | 是否必填 | 来源 | 说明 |
|--------|----------|------|------|
| `X-Auth-Key` | 是 | `config.authKey` | API 密钥认证；后端通过该 key 推导租户/用户身份 |

对于带有 JSON body 的 POST/DELETE 请求，还会附加：

| 头字段 | 值 | 说明 |
|--------|-----|------|
| `Content-Type` | `application/json` | 请求体为 JSON |

> 请求体中**禁止**携带 `user_id` 或 `tenant_id`，后端会显式拒绝。

### 2.2 记忆召回（输入联想）

| 项目 | 内容 |
|------|------|
| **用途** | 用户在聊天输入框输入时，根据当前文本召回历史记忆，用于生成输入联想建议 |
| **调用方** | `src/core/input-tracker.js` |
| **方法 / URL** | `POST /api/retrieval/search` |

**请求头**：`X-Auth-Key` + `Content-Type: application/json`。

**请求体**：

```json
{
  "query": "用户当前输入的文本",
  "agent_id": "echoagent",
  "session_id": "可选当前会话 ID",
  "limit": 5,
  "include_explain": false
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `query` | string | 是 | 用户输入文本 |
| `agent_id` | string | 是 | 应用级隔离标识，默认 `echoagent` |
| `session_id` | string | 否 | 当前会话 ID，用于会话锚定召回 |
| `limit` | number | 否 | 返回结果数量上限，默认 5 |
| `include_explain` | boolean | 否 | 是否返回召回解释 |

**响应体**：

```json
{
  "status": "ok",
  "result": {
    "items": [
      {
        "text": "记忆文本",
        "score": 0.85,
        "kind": "...",
        "source": "...",
        "evidence_uri": "..."
      }
    ],
    "explain": "..."
  }
}
```

源码消费：`result.items` 数组，元素至少读取 `text`、`score` 字段。

### 2.9 上传 Skill Package

| 项目 | 内容 |
|------|------|
| **用途** | 上传包含 `SKILL.md` 以及 scripts、assets、templates、references 等配套文件的完整 Skill Package |
| **调用方** | `src/panels/skill-store/index.js` → `EchoMemClient.addSkillPackage()` |
| **方法 / URL** | `POST /api/skills/package` |

**请求头**：`X-Auth-Key` + `Content-Type: application/json`。

扩展只接受 `.zip`，上传前限制原文件不超过 45 MB，再将文件内容转换为 Base64。该上限为 Base64 编码和 JSON 包装预留空间，避免超过 Chrome 单条扩展消息的 64 MiB 上限。Skill 名称由 EchoMem 从压缩包内的 `SKILL.md` 解析；压缩包目录、路径穿越、隐藏目录和可执行文件等安全规则由服务端统一校验。该请求默认超时为 120 秒，可由调用方通过 `timeoutMs` 单次覆盖；此配置只控制 Background 代理的请求等待时间，不会写入请求体。

**请求体**：

```json
{
  "package_base64": "UEsDB...",
  "filename": "example-skill.zip"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `package_base64` | string | 是 | ZIP 文件内容的 Base64 编码 |
| `filename` | string | 否 | 原始 ZIP 文件名，用于服务端校验和错误提示 |
| `name` | string | 否 | 可选名称；扩展当前不传，由服务端从 `SKILL.md` 解析 |
| `description` | string | 否 | 可选 Skill 描述 |
| `tags` | string[] | 否 | 可选标签 |
| `allowed_tools` | string[] | 否 | 可选工具列表 |
| `metadata` | object | 否 | 可选附加元数据 |

**响应体**：

```json
{
  "status": "ok",
  "result": {
    "name": "example-skill",
    "uri": "echo://skills/example-skill"
  }
}
```

### 2.11 获取 Skill 版本历史

| 项目 | 内容 |
|------|------|
| **用途** | 用户在「我的 Skill」点击「详情」时，按需读取当前版本和历史记录 |
| **调用方** | `src/panels/skill-store/index.js` → `EchoMemClient.listSkillVersions()` |
| **方法 / URL** | `GET /api/skills/{name}/versions` |

**请求头**：`X-Auth-Key`。`name` 优先取 Skill 真实目录名 `dirName`，缺失时才使用展示名，并进行 URL 编码。

**请求体**：无。

**响应体**：

```json
{
  "name": "example-skill",
  "uri": "echo://skills/example-skill",
  "skill_md_uri": "echo://skills/example-skill/SKILL.md",
  "current_version": 2,
  "versions": [
    {
      "version": 1,
      "parent_version": null,
      "path": ".skill_evolution/versions/v0001.SKILL.md",
      "source": "generated",
      "run_id": "run-1",
      "created_at": "2026-07-01T10:00:00Z",
      "current": false,
      "hash": "sha256...",
      "exists": true
    }
  ]
}
```

前端过滤非正整数版本，按版本号去重并倒序排列，以 `current_version` 产生唯一当前标记。

### 2.12 读取 Skill 历史版本

| 项目 | 内容 |
|------|------|
| **用途** | 用户点击「查看内容」后按需读取指定版本的完整 `SKILL.md` |

| **方法 / URL** | `GET /api/skills/{name}/versions/{version}` |

**请求头**：`X-Auth-Key`。`name` 优先取 Skill 真实目录名 `dirName`，缺失时才使用展示名，并进行 URL 编码；`version` 必须为正整数。

**请求体**：无。

**响应体**：

```json
{
  "name": "example-skill",
  "uri": "echo://skills/example-skill",
  "version": 1,
  "current": false,
  "path": ".skill_evolution/versions/v0001.SKILL.md",
  "hash": "sha256...",
  "text": "---\nname: example-skill\nversion: 1\n---\n..."
}
```

`text` 只在只读浮层中展示；前端使用 `textContent` 避免将内容当作 HTML 执行。

### 2.13 回退 Skill 版本

| 项目 | 内容 |
|------|------|
| **用途** | 用户确认后，将指定历史版本切换为当前 `SKILL.md` |
| **调用方** | `src/panels/skill-store/index.js` → `EchoMemClient.rollbackSkillVersion()` |
| **方法 / URL** | `POST /api/skills/{name}/rollback` |

**请求头**：`X-Auth-Key` + `Content-Type: application/json`。`name` 优先取 Skill 真实目录名 `dirName`，缺失时才使用展示名，并进行 URL 编码。

**请求体**：

```json
{
  "version": 1
}
```

`version` 必须为正整数。请求体不携带 `user_id` 或 `tenant_id`。

**响应体**：

```json
{
  "name": "example-skill",
  "uri": "echo://skills/example-skill",
  "skill_md_uri": "echo://skills/example-skill/SKILL.md",
  "version": 1,
  "rolled_back": true,
  "hash": "sha256...",
  "git": {
    "enabled": true,
    "status": "committed"
  }
}
```

Extension 仅以 `rolled_back === true` 判定业务成功。当前后端语义是切换当前版本，不表示创建新版本。

### 2.14 文件系统列表

| 项目 | 内容 |
|------|------|
| **用途** | 资源管理、Skill 商店中浏览目录内容，列出指定 URI 下的资源/文件 |
| **调用方** | `src/panels/resource/manage.js`、`src/panels/resource/import.js`、`src/panels/skill-store/index.js` |
| **方法 / URL** | `GET /fs/ls?uri=...&output=agent&abs_limit=128&...` |

**请求头**：`X-Auth-Key`。

**Query 参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `uri` | string | 是 | 要列出的目录 URI，如 `echo://resources`、`echo://skills`（**无尾部斜杠**，后端 `EchoUri.parse` 会拒绝末尾 `/`） |
| `simple` | boolean | 否 | 简化输出 |
| `recursive` | boolean | 否 | 递归列出 |
| `output` | string | 否 | 输出格式，源码中常用 `"agent"` |
| `abs_limit` | number | 否 | 绝对数量限制，常用 128 |
| `show_all_hidden` | boolean | 否 | 是否显示隐藏项 |
| `node_limit` | number | 否 | 节点数量限制 |

**响应体**：

```json
{
  "status": "ok",
  "result": [
    {
      "uri": "echo://resources/res_xxx",
      "name": "report.pdf",
      "resource_id": "res_xxx",
      "kind": "file",
      "size": 1024,
      "updated_at": "2026-06-22T10:00:00Z",
      "abstract": "..."
    }
  ]
}
```

源码消费：数组或 `result.entries` 数组；条目类型通过 `kind: 'directory'/'file'` 判断，不再使用 `isDir`。修改时间字段为 `updated_at`。

## 3. OpenView 统计与认证接口

默认基础地址：`http://127.0.0.1:31020`

### 3.1 登录

| 项目 | 内容 |
|------|------|
| **用途** | EchoMem 扩展登录 OpenView，获取 accessToken/refreshToken 用于后续统计接口调用 |
| **调用方** | `src/services/openview-client.js`（配置面板 `src/panels/echomem/config.js` 触发） |
| **方法 / URL** | `POST /v1/auth/login` |

**请求头**：`Content-Type: application/json`。

**请求体**：

```json
{
  "username": "...",
  "password": "..."
}
```

**响应体**（经 OpenView 统一包装 `{ code: 0, data: ... }`，客户端自动解包读取 `data`）：

```json
{
  "user": { "id": "...", "username": "...", "email": "..." },
  "accessToken": "...",
  "refreshToken": "..."
}
```

源码消费：`openview-client.js` 的 `login()` 保存 `accessToken`、`refreshToken`、`user` 到 `chrome.storage.local` 的 `openviewAuth` 键。

| 项目 | 内容 |
|------|------|
| **用途** | 效能概览面板展示用户会话级 Token 统计（总 Token、会话数、轮次数、Input/Output Token） |
| **调用方** | `background.js`（由 `src/panels/performance/index.js` 通过 `chrome.runtime.sendMessage` 代理调用） |
| **方法 / URL** | `GET /v1/stats/summary` |

**请求头**：`Authorization: Bearer <accessToken>`。

**请求体**：无。

**响应体**：

```json
{
  "total_sessions": 10,
  "total_turns": 42,
  "total_input_tokens": 1234,
  "total_output_tokens": 5678,
  "total_tokens": 6912,
  "since": "2026-01-01T00:00:00.000Z"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `total_sessions` | number | 总会话数 |
| `total_turns` | number | 总对话轮次数 |
| `total_input_tokens` | number | 累计 Input Tokens |
| `total_output_tokens` | number | 累计 Output Tokens |
| `total_tokens` | number | 累计总 Tokens |
| `since` | string (ISO 8601) | 统计起始时间 |

源码消费：`src/panels/performance/index.js` 的 `fetchPerformanceData()` 将上述字段映射为 `totalSessions`、`totalTurns`、`totalInputTokens`、`totalOutputTokens`、`totalTokens`、`since`。
