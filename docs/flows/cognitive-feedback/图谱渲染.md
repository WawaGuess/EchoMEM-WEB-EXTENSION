# 认知反馈图谱渲染

> 相关代码：`src/panels/feedback/index.js`, `src/panels/feedback/graph-three.js`, `src/services/graph-client.js`
> 面板系统：`docs/flows/panel-system/居中浮层.md`

## 概述

认知反馈图谱使用 **Three.js** 3D 渲染 EchoMem 引擎记忆图谱。数据来自租户引擎目录下的 `.graph` 存储：

```
echo://engine/echo0_plugin/memory/.graph
├── nodes/{atom,entity,episode}/*.json
├── edges/{about,contains}/*.json
└── adjacency/*.json
```

扩展通过 EchoMem HTTP API 的 `/fs/tree` 与 `/fs/read` 拉取节点与边文件，转换为 Three.js 场景对象后渲染。

当前仅展示 **实体关系**（`about` 边），即 `atom → entity` 的关系，不再提供会话关系切换。

## 技术选型

| 项目 | 选择 | 说明 |
|------|------|------|
| 渲染引擎 | Three.js | 3D 球体节点、曲边、力导向布局、OrbitControls 交互 |
| 打包方式 | npm 依赖打包 | 替换 ECharts，bundle 约 1.2MB |
| 布局 | 自研力导向 | 库仑斥力 + 弹簧引力 + 向心力，迭代稳定后渲染 |
| 动态效果 | 仅保留星空微闪 | 无粒子流动、无脉冲动画、无扫描线背景 |

## 数据获取

`src/services/graph-client.js` 负责：

1. 调用 `EchoMemClient.fsTree('echo://engine/echo0_plugin/memory/.graph', { maxDepth: 3 })` 列出所有节点与边文件。
2. 使用 `Promise.all` 并行读取文件内容并解析 JSON。
3. 将原始节点/边转换为渲染数据：

```javascript
{
  nodes: [
    { id: 'atom:atom-xxx', name: '用户询问...', symbolSize: 42, category: 0, value: 80 },
    { id: 'entity:用户', name: '用户', symbolSize: 45, category: 1, value: 50 }
  ],
  links: [
    { source: 'atom:atom-xxx', target: 'entity:用户', name: 'about' }
  ],
  categories: [
    { name: 'atom', itemStyle: { color: '#4facfe' } },
    { name: 'entity', itemStyle: { color: '#667eea' } }
  ]
}
```

节点分类与颜色：

| 类型 | category | 颜色 | 大小 |
|------|----------|------|------|
| `atom` | 0 | `#cc66ff` | 1.1 |
| `entity` | 1 | `#00e6ff` | 2.8 |
| `episode` | 2 | `#ffcc33` | 2.0（当前视图已过滤掉） |

当前仅渲染 `about` 关系，因此 `categories` 会同步过滤，图例和场景中均不显示 `episode`。

## Three.js 渲染器

`src/panels/feedback/graph-three.js` 负责 3D 场景搭建与交互。

### 节点渲染

每个节点由三层组成：

1. **主球体**：`MeshPhysicalMaterial`，带金属感和自发光
2. **内核发光**：`MeshBasicMaterial` + `AdditiveBlending`
3. **外层光晕**：半透明大球，营造 glow 效果
4. **文字标签**：`CanvasTexture` + `Sprite`，显示节点名称

节点样式：

```javascript
const TYPE_STYLES = {
  atom:   { color: 0xcc66ff, emissive: 0x6633aa, size: 1.1, opacity: 0.88 },
  entity: { color: 0x00e6ff, emissive: 0x0066aa, size: 2.8, opacity: 0.92 },
};
```

每个节点由 4 层组成：主球体、内核发光、外层光晕、装饰环，以及一个 `CanvasTexture` 文字标签。文字标签使用 `bold 26px` 字体绘制。

### 边渲染

`about` 关系使用二次贝塞尔曲线生成的管道：

```javascript
const curve = new THREE.QuadraticBezierCurve3(start, mid, end);
const tubeGeo = new THREE.TubeGeometry(curve, 24, 0.05, 8, false);
```

`about` 关系使用二次贝塞尔曲线生成的管道，默认颜色 `0x6688cc`，半透明并带自发光。

### 力导向布局

同步迭代 200 帧稳定布局：

```javascript
const K = 100;            // 斥力系数
const SPRING_LEN = 14;    // 弹簧目标长度
const DAMPING = 0.88;     // 阻尼
const CENTER_PULL = 0.006; // 向心力
```

节点按斐波那契球面初始化，经过斥力-引力-向心力迭代后稳定。布局完成后重绘曲边，并按节点主体位置自动调整相机（避免外层光晕导致距离过远）。

场景使用 60° 视场角、雾密度 `0.006`、ACES 色调映射（曝光 1.3），并包含星空背景与网格地板；渲染前会清空容器内的 loading 占位，避免 canvas 被遮挡。

### 交互

| 操作 | 行为 |
|------|------|
| 左键拖拽空白处 | 旋转视角（OrbitControls） |

### 渲染循环

仅更新 `controls` 和重绘场景，**无动态粒子/脉冲动画**：

```javascript
function animate() {
  animationId = requestAnimationFrame(animate);
  if (!container.isConnected) {
    cleanupThreeGraph(container);
    return;
  }
  controls.update();
  renderer.render(scene, camera);
}
```

## 渲染流程

```javascript
async function renderGraph(container) {
  setLoadingState(container);

  let graphData = container._graphData;
  if (!graphData) {
    graphData = await fetchGraphData();
    container._graphData = graphData;
  }

  if (!container.isConnected) return;

  const viewData = filterGraphData(graphData, 'about');

  if (viewData.nodes.length === 0) {
    setEmptyState(container);
    return;
  }

  renderThreeGraph(container, viewData);
}
```

## 容器生命周期

```javascript
export function getGraphOverlayContent() {
  const wrapperId = 'echomem-graph-wrapper-' + Date.now();
  const containerId = 'echomem-graph-container-' + Date.now();

  setTimeout(() => {
    const container = document.getElementById(containerId);
    if (container) {
      renderGraph(container);
    }
  }, 100);

  return `
    <div id="${wrapperId}" style="
      display: flex;
      flex-direction: column;
      width: 100%;
      height: 100%;
      min-height: 400px;
      background: #05070a;
    ">
      <div id="${containerId}" style="flex: 1; min-height: 0;"></div>
    </div>
  `;
}
```

浮层尺寸在 `src/core/router.js` 中配置：

```javascript
openCenterOverlay('认知图谱', getGraphOverlayContent(), {
  showBack: true,
  onBack: ...,
  width: '95vw',
  height: '90vh',
  maxWidth: '1400px',
  maxHeight: '900px',
});
```

## 错误处理

| 场景 | 行为 |
|------|------|
| 请求失败 | 容器显示"图谱加载失败" + 错误信息 + 重试按钮 |
| 无节点数据 | 容器显示"当前视图暂无数据" |
| 单个文件解析失败 | 打印 `console.warn`，跳过该节点/边，不影响整体渲染 |
| 面板关闭时请求完成 | 通过 `container.isConnected` 检查，避免操作已移除的 DOM |
| WebGL 不可用 | 浏览器不支持 WebGL 时 Three.js 会抛出错误，进入错误状态 |

## 已知限制

1. **WebGL 依赖**：需要浏览器支持 WebGL，极少数环境可能无法渲染。
2. **引擎 ID 硬编码**：当前默认读取 `echo0_plugin`，暂未提供配置入口。
3. **全量拉取**：每次打开均拉取 `.graph` 下全部节点与边文件，节点数量较多时性能会下降。
4. **无持久化**：不保存用户的历史知识图谱，每次打开都重新拉取。

## 后续演进方向
