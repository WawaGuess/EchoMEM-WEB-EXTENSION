# 资源查询流程

本文档描述 EchoMem Web Extension 资源管理中的「查询资源」功能实现。

---

## 入口

资源管理首页（`src/panels/resource/index.js`）提供两个入口：

| 入口 | 对应面板 | 说明 |
|------|----------|------|
| 上传资源 | `import.js` | 上传文件并浏览资源目录 |
| 查询资源 | `query.js` | 按多种维度搜索资源 |

---

## 查询维度

查询面板（`src/panels/resource/query.js`）提供 4 个 Tab：

1. **按 Session**：输入 `session_id`，支持「使用当前会话」快速填充
2. **按 Resource ID**：输入单个 `resource_id`
3. **按 Tag**：输入多个 tag，逗号分隔
4. **按 Metadata**：动态添加多组 key-value 条件

---

## 调用接口

```
POST /api/resources/search
```

请求体根据查询维度动态构造（`query` 必填，不可为空字符串）：

| 查询维度 | 请求体字段 |
|----------|------------|
| 通用 | `{ query: "搜索关键词" }` |
| Session | `{ query: "...", session_id: "..." }` |
| Resource ID | `{ query: "...", resource_ids: ["..."] }` |
| Tag | `{ query: "...", tags: ["..."] }` |
| Metadata | `{ query: "...", metadata: { key: "value" } }` |

`limit` 默认 16。

---

## 结果展示

后端返回的是资源片段（chunk），`query.js` 按 `resource_id` 分组聚合：

- 每个资源显示为一个卡片
- 卡片标题从 `echo://resources/{resource_id}/meta.json` 读取 `name`
- 显示片段数、更新日期、第一个片段摘要
- 点击卡片通过 `fs/read` 读取完整内容，在居中浮层中预览
