## 一、项目概述

本次改造涉及的项目：

| 项目 | 路径 | 角色 |
|------|------|------|
| EchoMEM Web Extension | `EchoMEM-WEB-EXTENSION/` | Chrome 扩展前端（Manifest V3） |
| EchoMem | `EchoMem/` | 记忆后端引擎 |

**核心目标**：将 EchoMEM 扩展的「资源导入」页面改造成类似 FTP 客户端的体验，支持文件上传、目录浏览，同时对接 EchoMem 后端 `/api/resources` 与 `/fs/ls` 接口。

### 2.2 各文件详细修改

#### `src/services/echomem-client.js`

新增资源相关方法：

```javascript
async addResource({ content, name, contentType, tags, metadata })
async deleteResource(resourceId)
async fsLs(uri, options = {})
async fsRead(uri, options = {})
```

- `addResource` 向 `POST /api/resources` 发送 JSON body。
- `deleteResource` 向 `DELETE /api/resources/{resource_id}` 发送请求。
- `fsLs` / `fsRead` 路径为 `/fs/ls` / `/fs/read`（不带 `/api/v1` 前缀）。

---

#### `src/panels/resource/import.js`（核心文件）

**功能模块**：

1. **本地文件上传区域**
   - 点击或拖拽上传（支持 PDF, DOC, TXT, MD）
   - 文件选择后调用 `doUpload(file)` 执行上传流程

2. **客户端读取文件内容**

   ```
   文本文件：file.text()
   二进制文件：FileReader.readAsDataURL(file) → 去除 data URL 前缀得到 base64
   ```

3. **异步上传与索引轮询流程**

   后端资源记忆引擎对资源进行异步索引（向量 + FTS），因此上传接口立即返回 `status=accepted`，前端需要轮询索引状态。

   ```
   Step 1: readFileContent(file)  → 得到 { content, contentType, encoding? }

   Step 2: addResource({          → POST /api/resources
             content,
             name: file.name,
             contentType,
             tags: [],
             metadata: { source: 'EchoMem extension', encoding? },
             sessionId: resolveUploadSessionId()
           })
           返回 { resource_id, uri, status: 'accepted' }

   Step 3: pollResourceIndexStatus(client, resource_id)
           → GET /api/resources/{resource_id}/index
           轮询间隔 1.5 秒，超时 30 秒
           直到 status ∈ {completed, failed} 或超时

   Step 4: loadRemoteFileList()   → GET /fs/ls?uri=echo://resources
           刷新当前目录文件列表
   ```

   - `resolveUploadSessionId()`：DeepSeek 使用 `getRecordingState().echoMemSessionId`；HIGO 从 URL `/home/session/{id}` 提取页面侧 `rawSessionId`。
   - 二期移除 `temp_upload`、`contentAbstract` 轮询和异步处理等待。

4. **远程文件浏览**
   - 根目录：`echo://resources`（**注意**：后端 `EchoUri.parse` 拒绝尾部斜杠，所有 URI 在发送前通过 `normalizeUri()` 去掉末尾 `/`）
   - 支持点击进入子文件夹、返回上级
   - 文件夹和文件分开展示（文件夹在上），按更新时间倒序
   - 后端 `fs/ls` 条目使用 `kind: 'directory'/'file'` 标识类型，不再使用 `isDir`
   - 显示隐藏文件（`showAllHidden: true`）
   - 过滤 `.DS_Store` 和资源记忆引擎内部目录 `.idx`

5. **文件删除**
   - 点击删除按钮 → `openCenterOverlay` 自定义浮层确认 → `deleteResource(resourceId)` → 刷新列表
   - 删除依赖后端返回的 `resource_id`，不再使用 URI 删除

6. **新建文件夹**
   - EchoMem 后端暂无 `mkdir` 能力，UI 中已移除「+ 新建文件夹」按钮

**关键状态变量**：

```javascript
let currentDirUri = 'echo://resources';  // 当前浏览目录（无尾部斜杠）
```

## 三、EchoMem 后端行为

### 3.1 接口清单

EchoMEM 前端调用的 EchoMem HTTP 接口：

| 接口路径 | 方法 | 用途 | 调用位置 | 关键参数 |
|---------|------|------|---------|---------|
| `/api/resources` | POST | 添加资源 | `addResource()` | `content`, `name`, `content_type`, `tags`, `metadata`, `session_id` |
| `/api/resources/{resource_id}` | DELETE | 删除资源 | `deleteResource()` | `resource_id` |
| `/api/resources/{resource_id}/index` | GET | 查询资源索引状态 | `pollResourceIndexStatus()` | `resource_id` |
| `/fs/ls` | GET | 列出目录内容 | `fsLs()` | `uri`, `show_all_hidden` |
| `/fs/read` | GET | 读取文件内容 | `fsRead()` | `uri` |

### 3.2 资源存储结构示例

```
echo://resources/
├── {resource_id}/          ← 资源目录
│   ├── content             ← 原始文件内容
│   └── meta.json           ← 资源元数据（name、content_type 等）
└── ...
```

## 五、验收标准对应

| 编号 | 验收项 | 实现方式 |
|------|--------|---------|
| 1 | 上传文件 | 客户端读取内容 + `addResource` |
| 2 | 文件列表显示 | `fsLs` 返回条目 |
| 3 | 列表刷新 | 索引状态到达终态或超时后调用 `loadRemoteFileList` |
| 4 | 删除功能 | `deleteResource(resourceId)` + 确认对话框 |
| 5 | 空状态 | 列表为空时显示友好提示 |
| 6 | 错误处理 | `formatError` 统一格式化上传错误；索引轮询错误单独处理 |
| 7 | 根目录变更 | `getRootDirUri()` 返回 `echo://resources`（无尾部斜杠） |
| 8 | 显示文件夹 | `fsLs` 返回的 `kind === 'directory'` 条目，过滤 `.idx` |
| 9 | 点击进入文件夹 | `loadRemoteFileList(uri + '/子目录名')`，发送前 `normalizeUri` 去掉尾部斜杠 |
| 10 | 返回上级 | `getParentUri()` + `loadRemoteFileList(parent)` |
| 11 | 路径显示 | `pathEl.textContent = currentDirUri` |
| 12 | 删除依赖 resource_id | 列表条目绑定 `data-resource-id`，删除前 `openCenterOverlay` 确认 |
| 13 | 移除新建文件夹 | UI 中隐藏按钮（后端无 mkdir） |
| 14 | 索引状态轮询 | `pollResourceIndexStatus()` 轮询 `GET /api/resources/{id}/index` |
