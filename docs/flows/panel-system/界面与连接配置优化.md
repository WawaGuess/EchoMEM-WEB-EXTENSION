# EchoMem 界面与连接配置优化设计

> 相关代码：`content.css`、`popup.html`、`popup.css`、`popup.js`、`src/core/panel-host.js`、`src/panels/echomem/`

## 目标

统一扩展入口、Popup、功能首页和右侧功能面板的视觉层级，使它们与 Echo Agent 的排版和交互节奏保持一致；同时把 EchoMem Auth Key 与 Base URL 的配置入口放到 Popup 中，移除对硬编码凭据的依赖。

## 范围

- 优化 Popup 的品牌区、连接配置、能力说明和状态反馈。
- 统一浮层背景、遮罩、标题栏、关闭/返回按钮、间距、圆角和动效。
- 统一资源管理、输入联想、Skill 管理、效能以及 EchoMem 功能首页的卡片层级。
- 保留现有面板注册、路由、事件、API、ID、class 和 data attribute。
- 保存配置时合并既有 `echomemConfig`，不覆盖 tenant、agent 等其他字段。

## 视觉原则

1. 使用 `Roboto, "Noto Sans SC", sans-serif`，通过字号、字重和留白建立层级。
2. 使用 Material 3 风格的紫色主色、浅色表面和低对比描边；功能色只用于识别，不改变业务含义。
3. 遮罩保持黑色半透明且不使用模糊，减少对宿主页面的视觉干扰。
4. 动效控制在 200ms 左右，并遵循 `prefers-reduced-motion`。
5. 保证键盘焦点、按钮语义、状态提示和移动宽度下的可读性。

## 连接配置交互

1. Popup 打开时读取 `chrome.storage.local.echomemConfig`。
2. 用户填写 Auth Key 和 Base URL 后点击保存。
3. 保存时仅更新 `authKey` 与 `baseUrl`，其余已有配置保持不变。
4. 空 Auth Key 在本地阻止提交；成功或失败通过 `role="status"` 文本反馈。

## 非目标

- 不新增 Episode、周期回顾或记忆花园功能。
- 不改变 EchoMem 后端接口、数据模型或请求语义。
- 不修改认知反馈内部的图谱、Episode、Summary 视图结构。

## 兼容性约束

- 常规功能继续使用右侧浮层。
- `.claw-overlay-panel`、`.claw-custom-panel-body`、`.claw-back-btn`、`.claw-close-panel`、`.claw-echomem-menu-item[data-panel-id]`、`.claw-config-section` 等既有选择器保持可用。
- Chrome 实际加载的 `dist/content.js` 由源码构建生成，不直接维护构建产物。

## 验证

- `npm run check`
- `git diff --check`
- 检查 Popup 配置读取、校验、合并保存和状态提示。
- 检查右侧面板打开、返回、关闭以及遮罩恢复。
- 检查窄屏布局、键盘焦点和减少动态效果设置。
