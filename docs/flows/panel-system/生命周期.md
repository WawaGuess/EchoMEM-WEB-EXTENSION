# 面板生命周期

> 相关代码：`src/core/panel-host.js`, `src/core/router.js`
> 配置参考：`docs/reference/面板注册参考.md`

## 概述

EchoMem 面板统一使用 `overlay` 浮层模式，从右侧滑入。面板生命周期包括：打开 → 渲染 → 调整宽度 → 关闭 → 恢复。

## 交互流程

```
用户点击 EchoMem launcher
    │
    ▼
打开 EchoMem 主面板（右侧 overlay 浮层）
    │
    ▼
点击功能菜单项（资源管理 / 输入联想 / 认知反馈 / Skill 管理 / 效能）
    │
    ▼
在同一面板内切换到对应功能内容
    │
    ├─ 详情页：左上角 ← 返回 EchoMem 首页
    └─ 右上角 × 关闭整个面板
    │
    ▼
关闭面板后移除浮层 DOM，页面恢复原始状态
```

## 打开面板

```javascript
export function openCustomPanel(title, contentHtml, options = {}) {
  // 如果已有面板，先关闭
  if (currentOverlayPanel) {
    closeOverlayPanel();
  }

  // 创建 overlay 面板
  createOverlayPanel(panelHtml, {
    position: 'right',
    width: '320px',
    backdrop: true
  });

  // 绑定事件
  bindPanelEvents(currentOverlayPanel, showBack, onBack, 'restore');
}
```

## 关闭面板

```javascript
export function restoreOriginalPanel() {
  // 1. 关闭当前 overlay
  if (currentOverlayPanel) {
    currentOverlayPanel.style.transform = 'translateX(100%)';
    currentOverlayPanel.style.opacity = '0';
    setTimeout(() => currentOverlayPanel.remove(), 300);
    currentOverlayPanel = null;
  }

  // 2. 移除遮罩层
  document.querySelectorAll('.claw-overlay-backdrop').forEach(b => {
    b.style.opacity = '0';
    setTimeout(() => b.remove(), 300);
  });

  // 3. 重置状态
  isCustomPanelOpen = false;
  setPanelOpen(false);
}
```

## 事件绑定

```javascript
function bindPanelEvents(container, showBack, onBack, closeMode = 'restore') {
  // 关闭按钮
  closeBtn.addEventListener('click', (e) => {
    e.preventDefault();
    e.stopPropagation();
    if (closeMode === 'overlay-only') {
      closeOverlayPanel();  // 只关浮层
    } else {
      restoreOriginalPanel();  // 关浮层 + 清理状态
    }
  });

  // 返回按钮
  if (showBack && onBack) {
    backBtn.addEventListener('click', (e) => {
      e.preventDefault();
      e.stopPropagation();
      onBack();
    });
  }

  // 遮罩层点击关闭
  backdrop.addEventListener('click', () => {
    if (closeMode === 'overlay-only') {
      closeOverlayPanel();
    } else {
      restoreOriginalPanel();
    }
  });
}
```

## 面板样式

- 默认宽度：`320px`（由平台配置决定）
- 拖拽缩放：拖拽右侧 overlay 的左边缘调整宽度，范围为 `320px` 至视口宽度的 `70%`，且最大不超过 `960px`
- 宽度记忆：拖拽结束后写入 `chrome.storage.local.echomemState.panel.width`，后续打开和面板内路由切换时复用
- 辅助操作：调整条获得焦点后可使用左右方向键；按住 Shift 时加大步长；双击调整条恢复默认宽度
- 位置：右侧固定（`right: 0, top: 0`）
- 高度：`100vh`
- 动画：从右侧滑入（`translateX(100%) → translateX(0)`）
- 遮罩层：`rgba(0, 0, 0, 0.5)`
- z-index：`9999`

## 平台适配

| 平台 | 面板位置 | 遮罩层 |
|------|---------|--------|
| HIGO Office | 右侧，覆盖在 MUI Drawer 上方 | 有 |
| DeepSeek | 右侧，覆盖在页面内容上方 | 有 |

居中 overlay 继续使用调用方传入的尺寸，不显示边缘调整条，也不读写侧边 overlay 的宽度偏好。

## 防重复注入

浏览器工具栏和 HIGO 标题栏属于同一个外部入口。两者先调用 `ensureEchoMemOverlayOpen()`：如果页面已经存在可见的 `.claw-overlay-panel`，保持当前实例与当前路由，不再次调用 `openCustomPanel()`。这可以避免连续点击不同入口时破坏遮罩和关闭状态。

面板内部的返回操作仍调用 `openEchoMemHomePanel()`，允许从功能页正常回到首页。

导航事件本身由 `bindPanelNavigation` 使用 `dataset.clawEventsBound` 防止重复绑定：

```javascript
if (customPanel.dataset.clawEventsBound === 'true') return;
customPanel.dataset.clawEventsBound = 'true';
```

从认知图谱等居中浮层返回时，需要重置该标记：

```javascript
export function openEchoMemHomePanel() {
  delete customPanel.dataset.clawEventsBound;
  bindPanelNavigation();
}
```
